## AI Builders 简报 Python 编排改造（最终方案）

### 架构
```
cron agentTurn(08:00) → AI执行 python3 builders-digest-cron.py
  → Python: node prepare-digest.js 拉数据
  → Python: subprocess调 openclaw agent --agent main 生成简报
  → Python: print简报到stdout
  → AI: 原样输出
→ cron announce投递 → 微信
```

### 关键决策
- 不用外部API（zhipu/glmcode直接HTTP调用），改用 openclaw agent CLI（自身对话能力）
- 用户明确要求：借用claw自身能力，不调外部API
- qqbot插件损坏已禁用（阻塞所有openclaw CLI命令）

### 脚本：`/root/.openclaw/workspace/scripts/builders-digest-cron.py`
- run_digest_script(): subprocess运行 prepare-digest.js
- call_claude_agent(): subprocess调 openclaw agent --agent main --json
- 不需要API Key，不需要模型配置，全走openclaw默认

### 验证结果
- 脚本独立执行：68秒，内容正常 ✅
- cron完整链路：80秒，delivered=true，用户确认收到 ✅
