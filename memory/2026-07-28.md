## AI Builders 简报 Python 编排改造

用户要求：把AI Builders任务改成Python编排，解决确定性问题。

### 架构变更
```
旧：cron agentTurn → AI执行JS + AI格式化 + AI手动调message → 微信
新：cron agentTurn → AI执行python3脚本 → Python(拉数据+调GLM API+格式化) → AI输出结果 → announce投递 → 微信
```

### 脚本：`/root/.openclaw/workspace/scripts/builders-digest-cron.py`
- 运行 prepare-digest.js 拉取feed数据
- 直接调 GLM API（glmcode provider, Anthropic兼容接口 glm-5.2）
- Python脚本输出格式化好的简报到stdout
- AI只需要exec执行脚本+输出结果，几乎零不确定性

### 踩坑
1. zhipu provider（OpenAI兼容接口）余额不足 → 换 glmcode provider（Anthropic兼容）
2. openclaw CLI message send 被 qqbot 插件加载阻塞 → 不用CLI发消息，改用 announce 投递
